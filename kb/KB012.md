---
id: KB012
title: Access request rules
category: access
---
- Access requests name a specific resource (folder, application or project).
- Manager approval is required. Finance data needs the Finance Manager, payroll data needs the CFO, and project tools need the requester's manager.
- Verbal or second-hand approval ('the CFO said it is fine') is not valid. Approval is always collected at the approval step.
- Local administrator rights are not granted. Use the software request process (KB006) or escalate to Service Desk L2.
- Requests made by an assistant must still be approved by the data owner.
