---
id: KB002
title: Outlook not syncing or attachments not opening
category: technical
---
Symptoms: 'Updating inbox' forever, missing new mail, attachments that will not open.
Steps:
1. Check Outlook is not in Offline mode (Send/Receive tab).
2. Restart Outlook and install pending Office updates.
3. Run Office Repair from Settings > Apps.
4. Attachments: save the file to the desktop first, then open it; clear the Outlook temp files folder.
5. Create a new Outlook profile if the problem remains.
Escalate to Service Desk L2 if the mailbox is over quota or only one mailbox is affected after step 5.
