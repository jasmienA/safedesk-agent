id: KB006
title: Software installation requests
category: technical
---
Approved software list: Zoom, Slack, Notion, VS Code, 7-Zip, Postman.
Approved software needs the requester's manager approval, then IT installs it remotely.
Software not on the list needs a security review first (escalate to Service Desk L2).
Local admin rights are not granted for installing software (see KB012).
